# shailong.me

Personal site — plain HTML/CSS/JS, no build step.

```
index.html     page content
styles.css     all styling (colors are the variables at the top)
script.js      "Ask me" answers (canned for now)
favicon.svg    browser tab icon
assets/        company + school logos
resume.pdf     ← add this yourself (see below)
```

## Before going live

1. **Résumé**: copy your résumé PDF into this folder and name it `resume.pdf`.
   It shows your phone number — remove it first if you don't want it public.
2. **LinkedIn**: done — links to linkedin.com/in/xinyulong.
3. **Ask me**: answers live in `script.js` — edit them anytime.

## Preview locally

Double-click `index.html` — it opens in your browser.
